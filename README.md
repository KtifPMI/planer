# 🚀 Tracker App

Мобильное приложение для отслеживания привычек, финансов, тренировок и планирования задач.

## Функции

- **Трекер привычек** — ежедневные чекбоксы, прогресс за месяц, цели
- **Финансовый трекер** — доходы/расходы, категории, план/факт, накопления, долги
- **Тренировки** — лог весов, прогрессия по упражнениям, история
- **Еженедельный планер** — задачи на неделю, цели, заметки, аналитика
- **Дашборд** — общая сводка по всем модулям

## Технологии

- **Flutter** — кроссплатформенность (iOS + Android)
- **Riverpod** — state management
- **Hive** — локальное хранилище
- **GoRouter** — навигация
- **fl_chart** — графики

## Запуск

```bash
# Установка зависимостей
flutter pub get

# Генерация Hive адаптеров
flutter pub run build_runner build --delete-conflicting-outputs

# Запуск
flutter run

# Сборка APK
flutter build apk --release
```

## Сборка через GitHub Actions

При пуше в `main` автоматически собирается APK. Скачать можно в разделе **Actions → последний workflow → Artifacts**.
